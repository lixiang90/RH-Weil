# 404. Adelic 周期轨道与离开单位元的 Weil 混合局部迹

2026-09-20。**[T/R] 局部计算及来源推论已通过Harvey独立逆审；新增推论由主线程另核原文。**
本稿回应[403](403-f1-support-locality-and-nonperfect-quotients.md)的混合配对检验。
得到的是实际算术作用的周期机制、局部固定点分布及其与固定 W 的范围内比较。
尚未构造 G5 的主除子根空间、算术平方上的全局交叉积、截面或 RR；没有 RH 结论。
局部迹和周期轨道本身是已有机制，不主张新颖性或 GOAL 第十节显著进展。

## 1. 先指定实际载体，而非以 W 定义对象

令 A_Q 为 Q 的 adele 环，K=∏_p Z_p^×，在无穷分量嵌入为1。
考虑实际双商集合

    X = Q^× \ A_Q / K。

R_+^× 通过只乘无穷分量作用在 X；用加法时间 s=log λ，记作用 T_s。
X 与 arithmetic site 的 Rmax 值点的同构类集合对应，且保持所述作用，引用 CC2015 Theorem3.8。
此处未断言点范畴、结构层或平方交叉理论的等价。
此处只需真实双商及作用，不把 X 当作通常概形，更不预设它的平方有 Cartier 交叉理论。

对素数 p，取 adele a^(p)，其 p 分量为0，其余分量包括无穷分量均为1。
则

    Stab_(R_+^×)([a^(p)]) = p^Z。

证明：若 λ 稳定该类，则存在 q∈Q^×、u∈K，把只有无穷分量乘λ后的 a^(p)
写成 q u a^(p)。无穷分量给 q=λ>0；每个 ℓ≠p 的有限分量给 q u_ℓ=1，
故 v_ℓ(q)=0。由有理数唯一分解 q=p^m。反向取相应单位 u_ℓ 即可。
因此作用轨道作为齐性空间为 C_p=R_+^×/p^Z，周期长度为 log p。
其标准周期空间结构与在 scaling site 中的实现见 CC2024 PDF2、4–5；
此证明本身只用双商与稳定子，不借用未证 RH 或 RR。

在实际集合平方 X×X 上令 Γ_s={(x,T_s x)}。
对 x∈C_p，若 t−s=m log p，则 (x,T_s x) 同时属于 Γ_s 和 Γ_t。
于是不同时间的图可以相交。403 的高度比函数满足“图在ρ=λ上”的附加假设
不能无条件搬到这些作用图上：周期点会被迫同时有不同的ρ值。

这已经给出与398的几何不同的机制。但作用图只是实际关系；
其“除子类”、叠加后的对象和交叉重数并未因此建立。

## 2. 实际局部固定点分布与测度约定

令 D_* = C_c^∞(R\{0})，把其元素延零视作 R 上光滑函数。
对局部域 Q_v 上的缩放 S_w ξ(x)=ξ(wx)，w≠1，
分布核为 δ(wx−y)。对角拉回合法，因为 x↦(w−1)x 可逆；其总质量是

    ∫ δ((w−1)x) dx = |1−w|_v^(-1)。

这是一条局部固定点／平迹计算；不是声明 S_w 是 trace-class 算子。
对实域可用分布拉回，对非阿基米德域用 Haar 测度的缩放恒等式；
Dirac 质量按所选加法 Haar 测度归一化，两种计算给同一雅可比因子。

固定乘法 Haar 测度：
- 在 Q_p^× 上令每个 p^m Z_p^× 的测度为 log p；
- 在 R^× 上令 d^×w = dw/(2|w|)，正负两个分量平均。

前者等价于 valuation 时间的格距 log p；后者将模长推前为 du/u。
这些是 CC2015 (12)–(15) 使用的归一化，不是未指定常数的迹。
对 k∈D_* 定义由上述局部缩放产生的量

    L_v(k)=∫_(Q_v^×) k(−log|w|_v) / |1−w|_v d^×w，
    L(k)=L_∞(k)+Σ_p L_p(k)。

因 k 在0附近消失，被积式在 |w|=1 的邻域为零；单位元正则化无需参与。
k 的支集紧使有限位贡献只有有限多个 p^m，因此不是条件收敛的全素数极限。

直接按 valuation 壳层计算，得到

    L_p(k)=log p Σ_(m≥1) [ k(m log p)+p^(−m) k(−m log p) ]。       (1)

正时间对应 |w|_p=p^(−m)<1，此时 |1−w|_p=1；
负时间对应 |w|_p=p^m>1，此时 |1−w|_p=p^m。
m=0 壳层因 k(0)=0 不贡献。

实位令 x=−log|w|，并平均 w 的两个符号，得到

    L_∞(k)=∫_0^∞ [ e^(2x)k(x)+e^x k(−x) ]/(e^(2x)−1) dx。        (2)

正时间系数为 [1/(1−e^(−x))+1/(1+e^(−x))]/2；
负时间系数为 [1/(e^x−1)+1/(e^x+1)]/2。
两者分别是 e^(2x)/(e^(2x)−1) 与 e^x/(e^(2x)−1)。
所有积分远离0且紧支，故绝对收敛。

(1)–(2) 是从局部域、作用和 Haar 测度计算出的分布；
它们作为全局 adelic 迹的几何侧是已有来源的一部分。
本稿不把“这些局部项的和已算出”升格为整个非紧双商上某个未指定算子的迹定理。

作用方向也可直接核对：周期λ=p^m在点上乘无穷分量，以主有理数p^(−m)重选代表后，
有限p坐标变为z↦p^(−m)z；函数上的逆拉回使用z↦p^m z，
故−log|p^m|_p=m log p，与(1)的正时间一致。这只是代表坐标核对，未额外构造横向几何。

## 3. 与仓库固定 involution 的精确归一化

仓库固定 k♯(x)=e^(−x)k(−x)。
若 k=k♯，则 k(−x)=e^x k(x)。代入(1)–(2)得

    L(k)/2 = Σ_(n≥2) Λ(n)k(log n)
             +∫_0^∞ e^(2x)k(x)/(e^(2x)−1) dx
           = N(k)，                                           (3)

其中 N 是403及 formal/F1/Analysis/Weil.lean 中固定的算术分布；
因为 k 在0附近消失，原定义的减项和 (logπ+γ)k(0)/2 均为零。
因子1/2必要：负时间的雅可比和 ♯ 对称性使两侧各贡献一份 N。
不能直接把全部时间的 L 当成 N，也不能用普通偶对称替代 ♯ 对称。

对实测试函数 f,g，
h=(f*g♯+g*f♯)/2 满足 h♯=h：
卷积的 ♯ 是代数自同构，且加法卷积交换。
若 supp f 与 supp g 不交，两个紧支集有正距离，故 h 在0的邻域消失。
于是可在这一对函数上独立计算 L(h)，并由(3)得到

    L((f*g♯+g*f♯)/2)/2 = W_pol(f,g)。                         (4)

这是离开单位元的混合局部迹比较，尚非全测试类上的几何交叉积。
“支集不交的函数对”也不是所有函数对组成的向量空间；
不把仅在这一适用域上的公式虚称为已定义的全局双线性型。

这里使用N的线性与W的实极化有通常数学的收敛依据：
任意q∈C_c^∞(R)满足e^(2x)q(x)−q(0)=(2q(0)+q'(0))x+O(x²)；
分母e^(2x)−1=2x+O(x²)，故零附近可积。远处剩余减项指数衰减，素数和有限。
因此线性与极化合法；未将Weil.lean中相应sorry登记为已完成形式证明。

## 4. 相差 log2 的固定检验

令 a=log2、0<ε<a/3，0≠φ≥0，φ∈C_c^∞((-ε,ε))；
取 f=φ、g=φ(·−a)。h 的支集在 ±a 的2ε邻域，h≥0，h(0)=0。
与403同样的直接代换给

    h(a)=(1/2)∫e^u φ(u)^2du >0。

故由真实局部缩放的(1)–(2)，

    L(h)/2 = W_pol(f,g)
            ≥ (log2/2)∫e^u φ(u)^2du >0。                      (5)

这里仍可能有其他素数幂项；不假设给定 ε 只截中2。
p=2 的正负时间壳层相加后再除2，恰贡献 log2·h(log2)。
这解释了非零项的实际局部算术来源，并通过403的必要混合检验。
没有获得 Γ_f·Γ_g 的已建全局除子交叉，也没有证明任何一般负性。

周期轨道长度的辅助检查：在标准圆 C_p=R/(aZ)、a=log p 上，
U_s ξ(t)=ξ(t−s)。对 k∈C_c^∞(R)，积分算子 ∫k(s)U_s ds
的 Fourier 特征值快速衰减，所以 trace-class，且 Poisson 公式给

    Tr(∫k(s)U_s ds)=a Σ_(m∈Z) k(ma)。

这解释正时间素数项的“周期长度×重复轨道”系数；
单独圆周迹的负时间没有 p^(−m) 权重，不能冒充(1)。
完整负时间权重来自局部横向缩放雅可比，而非周期长度本身。

### 4.1 固定有限S上的实际截断迹实现 [R/T]

独立代理进一步指出可直接接入Connes §VII Theorem4；主线程已回查PDF29–32，
并整页视觉核对PDF31。这比仅解释局部核更强，但仍是有限S的已知来源推论。

对给定k∈D_*，取M>0使supp k⊂[−M,M]，固定有限S，
包含∞和所有p≤e^M。令

    A_S=∏_(v∈S) Q_v，O_S^×={±∏_(p∈S) p^(m_p)}，
    X_S=O_S^×\A_S，C_S=O_S^×\∏_(v∈S)Q_v^×，
    h_S(c)=k(log|c|)。

此处有限p的指数为整数。C_S的模长核紧：
每类可用S单位把全部有限p的valuation化为0，再把实符号取正，
于是C_S≅R_+^××∏_(p∈S\{∞})Z_p^×。
所以h_S是该群上的光滑紧支测试函数，在p方向局部常值，且h_S(1)=0。

采用原文的L²(X_S)：S(A_S)按

    ||F||² = ∫_(C_S) |Σ_(q∈O_S^×)F(qx)|² |x|d^×x

分离并完成，d^×x的模长推前为du/u。固定原定理允许的基本加法特征，
其Fourier变换𝓕延伸为酉算子。置P_Λ为乘1_(|x|≤Λ)，
R_Λ=(𝓕P_Λ𝓕^(-1))P_Λ，U(c)ξ(x)=ξ(c^(-1)x)。

Theorem4给指定R_Λ U(h_S)的迹渐近：

    Tr(R_Λ U(h_S))
      =2h_S(1)log'Λ + Σ_(v∈S)∫' h_S(w^(-1))/|1−w|_v d^×w +o(1)。

h_S(1)=0；局部被积式在单位元附近为零，主值变为第2节普通积分；
S以外的p均不可能有±m log p落在supp k内。因此

    lim_(Λ→∞) Tr(R_Λ U(h_S)) =Σ_(v∈S)L_v(k)=L(k)。             (6)

先固定S，再取Λ极限。对第4节的h，(6)的一半正好为(5)。
任意更大的有限S给同一标量结果，但没有因此构造不同S的Hilbert空间、
对应、主关系和迹之间的统一几何比较，不能以标量稳定代替全局化。

R_Λ是两个正交投影的乘积，通常不是正交投影；本稿不从中推导正性。
这个[R]定理没有RH前提，也没有给全adele商上的目标除子交叉理论。

### 4.2 单位元项不能从这次检验恢复 [T]

若0≠f∈C_c^∞(R)为实函数，则

    (f*f♯)(0)=∫e^t f(t)^2dt>0。

因此D_*适用域不包含任何非零自配对的卷积。
在离开0的分布上加入cδ_0不改变(1)–(5)在D_*上的值，
却使半迹自配对改变(c/2)∫e^t f(t)^2dt。
这说明目前的局部检验不能确定对角常数，甚至已经通过所有这类检验也不够。

这是现有信息的非唯一性检验，不声称加入任意cδ_0仍满足原始全局几何／Fourier正规化。
若从来源固定主值和常数，它们可能决定唯一扩张；随后仍须证明该扩张来自所选完整τ。

这里既未把 output=N 设为对象的定义，也未声称 τ 已完整实例化。

非交换代数本身不自动属于390的交换ring模式。

后续必须分别完成：
1. 指定平方与对应的范畴，使 Γ_s 真正成为允许的对应，并定义其叠加；
2. 证明所选相对迹作用在这些对象上，含单位元、无限位常数及全局极限；
3. 从真实亚纯函数／截面定义主除子，验证它们在双次数和配对中确实为零；
4. 建立有效性、截面维数和足够强的 RR。单条周期轨道上的 RR 不替代平方上的 RR。

已成功的局部检验没有消除以上任一完整全局缺口。
