# 364. 中断整数候选的冻结验收

2026-09-10。旧周期13最终验证；不包含新的零点比例结论。
本节的有限验收不满足持续GOAL第十节C；后续主线转入F₁。

## 1. 被验收的确切对象

保持354窗口、alpha=1507/200000、eta=75571/20000000、delta=1/100000。
313控制值以1/80为单位；S=10^12，eS=5000000，偏置下界-7000000000。
采用[十轮迭代冻结记录](../reviews/2026-09-08/finite-control-integer-iteration.json)，
其中iteration-10数组的19730568条长word与原49、4234、194270条短word及空word组成W。
总计19929122个word、6237815186条控制边。前五轮账本是历史中途状态。

生成器最后一轮的缺口属于更新前的列表，不能用于断言更新后的候选是否闭合。
独立验证器冻结最终输入，只读扫描全部边，首尾核对输入哈希，且不导入松弛生成器。
向下费用的正确性继续引用[已审初始化](../reviews/2026-09-08/integer-initialization-independent-review.md)，
连续覆盖和曲率界引用[361整表复核](../reviews/2026-09-08/kernel-curvature-table-independent-review.md)。

## 2. 每条边所检查的命题

对尾word w=(w1,...,wl)，l≤4，控制z，记chi为(z,w1,...,wl)的前四项。
beta是以S为尺度的整数偏置，令

    C_lo(w,z) = beta_w + Q_lo(z) + eS
                  + sum_{j=0}^l F_lo(z+w1+...+wj),
    m(chi) = min { beta_v : v是chi的前缀，且v属于W }。

空前缀总在W内，beta_empty=0。逐边判定为m(chi)≤C_lo(w,z)，相等通过。
该条件连同偏置下界和已审曲率覆盖，充分给出361的连续认证。
四字child虽截断，费用仍保留五项能量；短word不补gap，e只加一次。

代码从实际短列表重建前缀最小值，不用生成器的中间队列判断是否稳定。
unique_suffix只优化child标签查询，inverse恢复每条原始尾边；费用没有取分组最小值。
偏置、费用与能量的界使中间整数绝对值<12S，313^4也小于int64上限。
最大缺口见证再以Python任意精度整数按原始word逐项重算。

## 3. 判定边界

正整数缺口首先说明这张冻结表没有通过向下费用的充分条件。
若另以区间算术证明真实费用下m(chi)>C(w,z)，则排除该表的精确同word／前缀闭合条件，
仍不能由此推出完整连续势h的残差为负：其他非前缀分支可能降低h(head)。
因此也不排除更强支配、更好的分支表或整个谱路线。

源码审查已通过，见[独立只读复核](../reviews/2026-09-10/frozen-control-independent-review.md)。

## 4. 完整扫描及严格见证

[扫描JSON](../reviews/2026-09-10/frozen-control-closure.json)记录全部输入身份、
逐层计数和见证；本次运行448.026秒，complete=true，首尾输入哈希一致。

全体偏置最小值为-6600529097/S，大于-.007。因此偏置下界已核验，失败在端点闭合。
最大整数缺口为126501794/S。对应控制z=520/80，尾word为
(979,531,1472,525)/80，beta_tail=-518821661。child的有效前缀最小标签
为-2152957262，向下费用候选为-2279459056。
全部存在的child前缀为长度0、1、4；验证器已对长度2、3的前缀作精确查找，均不在列表中。

[320位Arb复算](../reviews/2026-09-10/frozen-control-witness-arb.json)得到

    m/S - C_true = 0.000126501792208110240669331245879... > 0,
    C_true - C_lo/S = 1.791889759330668754... × 10^-12。

所报有理端点严格包围真实值。此缺口不是取整所致。
若只放大统一端点损失来补救同一冻结表，至少需要
e_required > 0.0001315017922，而361即使不支付曲率也要求e≤delta=0.00001。
所以该表不能靠重分配现有曲率预算通过同一前缀充分准则。
这仍不排除非前缀比较或不同分支表，不宣称完整连续h已有反例。

结算：旧周期13被中断的最终验收已完成，结论是当前冻结候选失败。
没有从该候选获得无条件比例；不继续为通过验收而无限松弛。下一主探索为F1-EX1。

## 5. 复现入口

需要numpy及原初始化要求的python-flint 0.9.0；后者的固定安装记录位于
[interval-runtime.json](../reviews/2026-09-08/interval-runtime.json)。
大数组丢失时，在仓库根目录按下列命令重建；生成脚本会写本地tmp/control-closure。
已有冻结数组时直接执行后两项。重建的运行时长字段可以不同，数据哈希必须相同。

```text
python scripts/finite_control_integer_initialization.py
python scripts/finite_control_integer_iteration.py --rounds 10
python scripts/verify_frozen_control_closure.py
python scripts/verify_frozen_control_witness.py
```

已存数组身份、控制表及初始化SHA由冻结JSON逐一给出；验证器不以数组文件名代替哈希。
