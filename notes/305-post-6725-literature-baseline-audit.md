# 305. 67.25% 之后的文献基线核查与研究目标修订

日期：2026-09-06。范围：Riemann zeta 的简单临界线零点比例，以及与该路线直接相关的后续证明、计算证书和方法障碍。本文是文献审计与常数复核，不是新的零点比例定理。

## 1. 本轮结论与计数口径

**公开研究稿已经超过 67.3%，不能再将 67.25% 写成全部公开研究的最新数值。** 已定位 ainta 的 67.3008527928%、trmdy 的 67.3312742272%、Shi 的 67.3316977142%，以及 Devine 2026-08-23 稿件声称的 67.3399%。它们的证明与复核状态不同，不能仅按小数排序就宣布数学界已确认的新纪录。

这里比较的是
\[
 \liminf_{T\to\infty}
 \frac{N_0^s(T,2T)}{N(T,2T)},
\]
分母计非平凡零点及其重数，分子计简单且位于临界线的零点。比例写成百分数需乘 100；这是渐近下界，不是有限高度零点验证，更不是 RH 的完成百分比。不同零点比例必须另核其完整账本，不能仅凭上述简单零点计数套用 \(D\ge(N+S)/2\)。

本轮未找到可据以将上述 67.3% 以上草稿统一标为“外部同行评审已完成”或“数学界已公认纪录”的证据。另一方面，未完成同行评审不等于已经发现数学错误；引用已证解析定理也不自动使结果具有新的未证数学假设。这里区分的是**作者主张、证明依赖和本项目已完成的核查**。

原始 PDF、固定版本与下载校验值统一见 [文献索引](../literature/README.md) 和 [manifest.json](../literature/manifest.json)。

## 3. 67.3% 的直接出处：ainta

ainta 的正文使用与 304 相同的凸谱余项
\[
 \Psi(t)=(t-1)^2-(t-2)_+^2.
\]
其有限维稳定性引理保留
\[
 \|P+Q\|_F^2\ge4\operatorname{tr}(P+Q)-3r-4b+
 \operatorname{tr}\Psi(V^*V),
\]
再通过原论文的迹、尾项和重数/惯性账本得到
\(S\ge C_0N+\operatorname{tr}\Psi(M^\circ)-o(N)\)。
这不是将可被其余零点抵消的 HS 偏差直接相加。

七点有限不等式的目标为 \(19/5000\)，压力为 \(1/3000\)，取全局固定块长 \(m=269\)。正文保留了大跨度/小跨度分支、紧集上一致 Gram 近似、平移分块平均与端点误差，最后给出
\[
 p_7=\frac{1345000C_0-2680}{1340003}
 =0.6730085279277797613\ldots,\qquad
 C_0=\frac32-\frac1{\sqrt2}\cot(1/\sqrt2).
\]
本轮用有理 Taylor 包络独立确认 \(p_7>673/1000\)。但这个常数计算不证明所需七点核不等式；原仓库报告 707901 个搜索节点、深度 37，本轮没有重跑它。

其 [三点推导](https://github.com/ainta/zeta-simple-zeros/blob/040c5e899e658aed7b56a2a87f501798fe10761d/docs/proof.md) 更直接影响 304：同样使用三个间距 \(u,v,u+v\)、MT 核根的加法障碍、不交三点及
\[
 p_3=\frac{C_0-\epsilon_4/4}{1-\epsilon_4/2}.
\]
其公开证书取 \(\epsilon_4=221/10^6\)，给
\(p_3=0.6725197671136777\ldots\)，高于 304 取 \(10^{-4}\) 得到的
\(0.6725093291458689\ldots\)。

**修订新颖性结论：304 的核心三点机制已有直接公开对应，且已有更强三点数值。** 304 的证明仍可作为项目内部小型有理证书和直接 Hilbert 接口的复核基准；这些实现差异是否构成独立贡献需单独论证，不能据其超过旧 \(C_0\) 就宣称前沿改进。

## 4. 七/九点后续与核查深度

归档时另核实：trmdy仓库附带PDF的作者为Vivaswat Ojha，日期2026-08-11，正文主结果仍是67.3200117013%的七点版本。上述较高九点值来自后续文档，已单独保存[固定版本补充材料](../literature/supplements/trmdy-nine-point-1610b97.md)，不能将它误引为该PDF的主定理。

trmdy 的最终九点目标为 \(15211/2500000\)，压力 \(1/2500\)，使用同一经过扰动的余弦窗。七点和九点 JSON 在固定提交中使用完全相同的七个窗口系数；本轮逐项核对非负有理权，并精确验证每个间距跨度的总容量等于 2。

九点日志记录两组不交分片 \([0,64)\)、\([64,96)\)，合计 96 片、116272426 个节点，表哈希一致。这只是**对公开运行记录的核对**，不是本轮重新验证全部叶节点；JSON 中遗留的“awaiting verification”等设计字段也不能覆盖后来的日志，更不能由日志反过来替代独立复跑。

Shi 同时使用该窗的七点和九点约束，在固定 \(m=219\) 的迹–能量包络上建立支持平面。其常数可写为
\[
 H=\frac{3362285207}{5000000000},\
 A_7=\frac{189783}{200000},\
 A_9=\frac{3209521}{2500000},\
 R=2\sqrt{\frac{349837789}{273750000}}-1+\frac{A_9}{219},
\]
\[
 u=\frac{R-A_7}{A_9-A_7},\qquad
 B=\frac{219H-(1-u)213\cdot6/2736-u211\cdot8/2500}{219-R}.
\]
本轮核对支持平面证明的分段条件，并以有理根式包络复算
\[
 B=0.67331697714247131348\ldots>673316977/10^9.
\]
它比 trmdy 上述九点数值高约 \(0.0004234870\) 个百分点。

[Shi 的 Lean 说明](https://github.com/yuhangshi888/zeta-simple-zeros-673316977/blob/7cfd0ce9a9ef1615889b5c1191fac5de41f13960/lean/README.md)明确把局部证书、解析稳定性接口、Gram 渐近、全局分块平均及谱包络前件留在形式化范围之外。因此“局部 Lean 检查通过”不能转述为整个零点比例定理已经端到端形式化。本轮也未运行其 Lean 工程。

## 5. 其他更新与应排除的混淆

Devine的[本地v3原稿](../literature/candidates/2026-devine-673399-v1.0.3.pdf)第1、7页具体注明：公开包含紧凑证书核心，而完整形式化可重放数值包仍在准备。这是后续独立认证必须核对的交付边界；不能只读“PASS”就认为所有数值材料均已在本项目重放。

- **67.3399%**：Devine v3 使用多个带限窗及有限相互作用，并附公开认证包。本轮将其登记为必须比较的后续主张，尚不导入项目证明链。原 [67.92% 稿件](https://zenodo.org/records/21879591) 则明确要求消失窄箱假设；v3 中超过 67.92% 的部分也有条件，不能与无条件比例混写。
- **79.62%**：[Yang–Yang 稿件](https://zenodo.org/records/21975237)自标 certified-candidate，解析高矩链未在本轮核查。有限矩常数、体积证书或部分 Lean 恒等式不能替代实际 zeta 高矩渐近。本项目 MOM-1 的未证预算并未因此自动解决。
- **密度 1**：[同作者后续记录](https://zenodo.org/records/22065921)当前处于封存状态，注明“版本内容有错误，需要重新修订”。只记录警示和来源，不纳入结果基线，也不尝试取得被封存附件。
- **68.1810782%**：[Hydra Dynamix 的 2026-08-31 报告](https://www.hydradynamix.com/blog/a-tighter-ceiling)讨论的是某类带宽一方法的上限证人，方向是方法能力的障碍，不是实际简单零点比例下界。本轮未独立复算其证书。
- **2026-09 的解析进展**：Lamzouri 的新短证以及 [BGST v3](https://arxiv.org/abs/2501.14545v3) 的范围与勘误需要纳入引用。新发布日期不自动意味着更高的比例。

## 6. 对看板与 GOAL 的具体修订

1. 采用两栏基线：已经纳入项目证明链的外部/内部结果，以及已发现但未完整认证的后续主张。\(C_0\) 和 304 保留精确历史值；公开比较至少覆盖 67.3008528%、67.3316977% 和 67.3399%。
2. MOM-STAB 的核心新颖性对照已完成到足以否定“首次三点机制”与“仅超过 67.25% 即前沿”这两种表述。后续限于真正未覆盖的接口、证明简化、证书可审计性或新模型；不自动展开更多块数。
3. MOM-1 的目标应是新实际算术输入和完整条件解除。若目标比例为 \(p\)，正确四矩阈值为
   \[
   B_4<\frac{(1-v)^2}{p}-1+2v,
   \]
   并须保留 228 的误差、参数及重数/惯性条件。平窗 \(v=1/3\) 下，以 67.3% 为比较值需
   \(B_4<0.327059600462275\ldots\)；以待审 67.3399% 为比较值需
   \(B_4<0.326668306770742\ldots\)。
   实际 MT 窗 \(v=1-C_0\) 对后者的阈值约为
   \(0.326602198303353\ldots\)。
   原 \(0.3275499074\ldots\) 只对应平窗下超过旧 \(C_0\) 的门槛，不能标成超过最新候选的门槛。
4. 67.3399% 在这里是**待审比较标尺**，不因设置目标而被认证。对更高但未核查的声明也不机械设“必须超过”的门槛；应先审计其适用条件、实际算术输入与证书。
5. 数值结果、方法上限、条件比例、纠错/复核贡献分开登记。保留同一谱余项只能计一次；不得把 Schur–Jensen 与 \(\operatorname{tr}\Psi\) 当两份独立增益相加。
