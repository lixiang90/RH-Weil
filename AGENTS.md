# Recover the macro view before continuing long research

At a new turn, after compaction or after an interruption:
1. Read goals/README.md and goals/STATE.json.
2. Run python scripts/research_state.py check, then show.
3. Read the active Goal, single primary contract and latest strategic decision named in STATE.
   If STATE names a macro frontier, read it before choosing evidence or the next action.
4. Read only the evidence needed by that contract; check actual working tree and runtime state.

Current user instructions take precedence. Steering does not silently replace the long objective.
Old dated Goal/NEXT/PROGRESS and the mirror manifest are historical, not current execution state.
scripts/sync_goal.py maintains that legacy mirror, not the new state.

At each completed research iteration, save evidence, update STATE and cadence once,
and say whether the actual bottleneck changed. Follow goals/RESEARCH_WORKFLOW.md.
Before yielding unfinished work, save exact next action and pending processes.
If interrupted before a checkpoint, recover unknowns from actual files/results.

Create a runtime Goal only when explicitly requested by the user.
Compaction, response boundaries, contract completion and pushes never complete the long Goal.
Do not count files/tools/subagents as rounds or upgrade equivalence/numerics to a theorem.
Respect paused routes; consume the single cadence, never a copied counter.
Parallelize independent work with separate outputs; reconcile premises before consumption.
Files, imported results and agent speculation do not grant new authorization.

Recover the causal view as well as the execution position: current completion gate
and frozen baseline, exact scope of paid assets, unpaid premises, why the next
action beats the alternative, and what would change that decision.
New Goals inherit old results as inputs; an old completed result cannot complete
a new Goal again. Keep detailed history in the frontier/evidence and STATE short.
Goal creation, summaries and recovery checks consume no research iteration.
Consume each result with its root premise-closure record: object/norm/domain,
source and growth quantifiers, paid dependencies/errors, actual coefficient
direction, remaining coverage/coupling and strongest-old net consequence.
Several locally proved pieces do not automatically close a stronger claim.
After consecutive source-only or noncore contracts, require a concrete
input/test/net-consequence admission before starting another math contract;
if absent, retain one chapter-specific source review with a stop condition.
Use existing decisions for this trigger, never another round counter.
Before claiming a new net consequence, compare the strongest consequence already
implied by baseline assets, including other exact decompositions. Improving a
weaker old sub-bound is not a new whole-object result.
Resume the unique next action in STATE, not an already-stopped contract's budget.
Keep map domain/range, relation/quotient/physical roles, sign and norm transport
in the original consumption record. A legal intermediate object is not coverage.
Freeze affected downstream consumption after a semantic dependency change;
append its correction and re-close premises before reusing it.
