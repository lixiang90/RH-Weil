2026-10-20；为本轮综合路线图提供独立来源核查。只作来源恢复、范围比较与研究准入建议，

## 1. 检索结果中最需要保留的三个范围区别

**Mellin 对偶不是自动存在的正算术对偶。** Hilberdink—Lapidus 已发表论文给出
“已给两个 Mellin 对象”的函数方程与反演恒等式的等价判据；有关一般连续 dual g-prime
系统的更强结果，是该文对 Lapidus—Nest 准备中工作的转述。本轮没有取得后者可独立核验的
完整证明。当前能访问的作者书目仍把相应篇名列在 preparation 部分；这不能证明它们从未
发表，但足以禁止把未取得的定理当作本仓已付资产。

**ζ(∂c) 的谱是 ζ 在竖线上的值域闭包，不是 ζ 的零点集合。** 自伴的动量算子
与正常的量子化 ζ 提供严谨载体与谱映射；将这套载体直接叫作 Hilbert—Pólya 零点算子，
会改变对象。准可逆性和通常可逆性还需分开。

**给定函数的 faithful determinant 编码，不是从计数源独立构造正性。**
Cobler—Lapidus 的后续工作对此有格外明确的自我限定：其 ζ 算子构造预用零点，
真正需要另找的是几何/上同调来源，再证明得到同一行列式比。

## 2. 原始文献账本：什么能消费，什么仍未支付

### L1. Hilberdink—Lapidus 的 Beurling 与广义函数方程

[arXiv:math/0410270v1，2004](https://arxiv.org/pdf/math/0410270v1)，
[Acta Appl. Math. 94 (2006), 21–48，DOI](https://link.springer.com/article/10.1007/s10440-006-9063-0)。
作者个人主页亦将其列作已发表 JA44。原 arXiv PDF 有重复 §3.2；以下按带编号命题定位，
不把重复排版当作第二个定理。

- §2 Theorem 2.1：广义 ψ 的幂次误差给右半平面延拓和无零；反向还需对
  −ζ′/ζ 的竖直增长控制。计数/零自由字典不是无条件平方根界。
- §3 Proposition 3.1、Theorem 3.2、(3.5)–(3.6)：固定核 Gr 与 Fr，在相应增长、
  Mellin 条带、有限极点及衰减条件下，Ψ1(1−s)=Ψ2(s) 等价于
  F1(x)=x⁻¹F2(1/x)+有限 power-log 缺陷；g-integer 特化是 Ψr=Grζr。
- §1.3 的分形膜 partition function 是 g-integer 能级的热配分函数；它实现 Euler 侧，
  不自动实现非平凡零除子。

可迁移设施是核/背景、有限缺陷及两对象之间的 Mellin transport。没有给定标准完成背景、
预先的分次权、正极化、RR 有效性或任意正 P 的自然正 dual 存在定理。
本范围与 564 已核消费一致，不重计。

### L2. Lapidus—Nest 转述及分形膜研究纲领的证据状态

[HL 原文 §3.2 后 Remark](https://arxiv.org/pdf/math/0410270v1)，
[Lapidus 作者书目 preparation 部分 Pr3–Pr5](https://math.ucr.edu/~lapidus/theListofPubs.pdf)，
[2008 年专著作者提供的 introduction/excerpt](https://math.ucr.edu/~lapidus/bookexcerpt2.pdf)。

原 Remark 所称 dual 一般会涉及连续 g-prime 系统，且离散部分问题仍困难。
2008 专著目录 §4.2/4.2.1 是二次量子化与 spectral triple 模型，§4.4 是 cohomological
解释的猜想，§5 是模空间/流的研究纲领；introduction 明确区分定义、定理与 speculative 部分。
作者书目中的同题 Nest 工作仍标 preparation；本轮未取得可核后续全文。

这给出一个值得保留的组织观念：Euler 的正热配分表示、对偶、模空间流、零点的上同调
实现是不同层级。谱三元组中 D 自伴不能直接推出 partition function 的零点纯性。
检索不到完整后续文稿只记为“本轮未取得”，不宣称数学上不存在该结果。

### L3. Herichi—Lapidus 的正常算子框架与准可逆性

[arXiv:1210.0882v3，2013](https://arxiv.org/pdf/1210.0882v3)，
Contemporary Mathematics 600, 51–89。按正文 Theorems 3.7、3.9、3.15、3.17、5.9、6.1 核读。

载体为 Hc=L²(R,e⁻²ct dt)，∂c 的 adjoint 是 2c−∂c，且 ∂c=c+iVc，Vc 自伴、谱为 R。
ac=ζ(∂c) 是通常不有界的正常算子；其谱为 ζ(c+iR) 的闭包。
c>1 时量子 Dirichlet 系列在算子范数中成立。Theorem 5.9 是
ac 准可逆 ⇔ ζ 在该竖线上无零；Theorem 6.1 对全部非中心 c 的量词给 RH 等价式。

这些是已证的载体、域与谱映射设施；无零方向在字典另一端仍是需要证明的内容。
不能把 Vc 的全实轴连续谱改说成全部非平凡零点的离散谱。

### L4. Lapidus 的不对称“通常可逆”判据

[arXiv:1501.05362，2015](https://arxiv.org/pdf/1501.05362)，正文 §4 Theorems 4.1–4.5，
§5 Theorems 5.1–5.3。

Theorem 5.1：对全部 0<c<1/2，ac 通常可逆 ⇔ RH。
Theorem 5.2：对每个 1/2<c<1，ac 无条件不通常可逆，因为 ζ 的竖线值域稠密、谱含 0。
故无实际零点也不保证通常可逆：值域可以趋近 0。Theorem 5.3 将 ac*ac 的正算子
“有正谱隙”列为等价条件；正性本身免费，所需谱隙没有免费得到。

这也解释为什么不应仅凭早期 1203.4828 abstract 的 invertibility 用词制订路线；
后续明确的准可逆/通常可逆区分更适合作为本仓范围基准。

### L5. Cobler—Lapidus 的零除子与正则行列式

[arXiv:1705.06222v4，2017](https://arxiv.org/pdf/1705.06222v4)，§4/4.1、§5.4、
§5.5 Theorem 31、§6。版本信息为正文首页 20 June 2017。

给定零点/极点多重集后，构造 weighted Bergman derivative 的直和/限制，
再用零点倒数进入 Schatten 类与正则行列式，得到 finite-order entire 函数的
quantized Hadamard factorization。§6 明说该 ζ 构造用了 zeros，不能直接证 RH；
需独立几何来源恢复同一 determinant ratio。

可迁移的是重数、Schatten 阶、正则乘积的严格账本。它不生产 independent source form，
也不能拿“有某个算子和完整 determinant”代替几何正性。

### L6. Lapidus—Lũ’—van Frankenhuijsen 的局部几何与误差账本

[arXiv:1603.09409v4，2018](https://arxiv.org/pdf/1603.09409v4)，
§3.1 languidity、§6 Theorem 6.1/Corollary 6.3、§7–8。

其 p-adic tube formula 在已给 screen/growth 前件下，是对 Cc∞(0,∞) 的分布身份，
带明确 screen 积分余项和分布 O 估计；strong languidity 下可在指定支持类去除误差。
这提供合法截断、移动轮廓、极点/剩余量比较的范例。局部半径取 p 的整数幂及
Haar measure 是实际额外数据；不能由任意连续 P 自动恢复。

文中 §7 的 adelic/global 谱与 §8 的 Euler–Riemann string 要区分已给具体模型和后续纲领。
精确 tube formula 描述给定复维数，不独立强制它们单线；文中 Fibonacci 例甚至有多条竖线。

另参考 [arXiv:2012.11535，2020](https://arxiv.org/pdf/2012.11535)：构造有理维数 p-adic string
及 adelic Cantor 类对象。可用于检验 local-to-global 的定义，不能直接消费为全源正极化。

## 3. 扣除本仓强旧资产后，Lapidus 方向该放在哪个位置

564 的同整数正 Fourier-selfdual gB 已表明：宽核对偶加正核并不固定 completed divisor。
565 的标准 Gamma 类唯一性和 Gaussian 基态 selector 可以排特定 gauge，但前者需要类
membership，后者使用额外局部 metric；均不付款完整 Weil Q 的符号。

562 已有正连续 primitive 的居中段/离线段及分支混合，说明“一般 g-integer”不应被定义成
离散算术 comb。563 付全递推加独立能量证书的平方和；566 付函数域 unitary bundle 的
全部 winding/全时间普通热迹身份，同时证明 safe jump 的普通 trace 问题及 physical Q
全线闭包障碍。567 的全 Π formal graph 负测试进一步排除了“有对偶/复合/trace 即有 Hodge”的跳跃。

更早的 081/082 也值得在路线图中明确恢复：081 已有无条件正 Hilbert norm、Mellin ζ
乘子、有限 PSD Gram/Schur distance，而目标距离趋零仍等价 RH；082 说明正 Gram 的
uniform gap 路径会受越来越密的 log-node 碰撞影响，真正未付的是 target 的低谱耦合。
故本轮不能把 Lapidus 的正正常载体、ac*ac≥0 或新正 Gram 重新计作 independent positivity。
这里“Beurling”还须消歧：081 的 Nyman—Beurling 密度判据，与 L1 的 generalized primes
理论是不同工作流，虽都可通过 Mellin 连接，不能仅凭名称合并已付前件。

因此最可消费的定位是：

| Lapidus 设施 | 可贡献的箭头 | 与曲线独立正性之间还缺什么 |
|---|---|---|
| measure/string 与 Mellin transport | P/Π/M、背景核、双对象和极点缺陷的明确对象 | 固定规范和权；不能由 FE 产生 RR |
| weighted shift 与 functional calculus | 非离散载体、合法域、正常谱与 resolvent 问题 | 完整 Weil 源的 positive functional/Gram 来源 |
| tube formulas 与 screens | 全源/截断/余项身份的严谨范式 | 同一 cutoff 的误差须小到能传递 signed primitive 符号 |
| Bergman determinant | 保完整除子与重数的比较目标 | 从 P 和对偶独立构造，且不先放入目标零点 |
| Fock/membrane partition function | 正 Euler 侧的谱配分表示 | 从能级 log(g-integers) 到零除子/primitive cohomology 的额外桥 |

这是来源职责分配，不是这些论文合起来已蕴含 RH 的断言。
原 actual ζ 的 542+555→557 whole leading 4/5、560 成长 K/sign/coupling 与 faithful Ξ 责任不变。

## 4. 后续三个可以判定真假的门

### Gate A：完成背景固定后的 source-first dual carrier

具体输入：固定 P、全 Π、M 及 admissible completion/background，不允许末端自由乘 B；
给实权中心和对偶 map，明确它在源空间、商空间及物理读出分别怎样作用。
先在 Zc 连续正负段、F5 曲线以及 290 反模型上核对全部 pole/contact/重复幂。

可利用 L1/L3 的 Mellin/shift 组织，但须实际展示 canonical adjoint/degree/trace 角色。
**成功门**是得到以后可与几何比较的明确域/源身份；这本身只是一项设施。
若结果仍只是已有 Ψ1(1−s)=Ψ2(s)，或对正负段毫无区分地宣告 positivity，即停止。
不将正文未取得的 Nest 定理填作空缺。

### Gate B：RR/有效性所需的乘法与容量，而非再选一个正 Hilbert 空间

具体输入：从 same source 给出截面对象、乘法、有效对象的非负 degree、有限 cutoff 容量，
并计算 567(13)–(14) 所需的二次项、误差和完整 Γ diagonal finite-part。
Fock construction 可提供现成 Hilbert 空间，却只有能独立产生这些截面/有效性数据才进入本门。

**最便宜负对照**是 567 两连续段和 290：它们已有正计数与形式对偶；
设施必须在某个具体 RR/容量/有效性前件失败，不能仅事后说“它不几何”。
**成功门**是一个未使用零点、可比较 signed primitive form 的误差预算。
若只得到 dim/partition trace 或以未知 H¹=Q 作定义，则来源停，不开未知 cohomology 合同。

### Gate C：faithful determinant/heat 比较作为最后识别，而非起点证书

输入须是 Gate B 或另一独立来源已经构造的算子/正型；再用 L5 的 Schatten/乘积账本
证明其 heat 或 determinant 正好对应全 Γ/prime-power/pole 源，包含所有重数。
对于连续谱 state 用相应 positive functional 与合法 relative determinant；
不能强迫普通 trace，也不能把 signed relative trace 自动当正 trace。

**成功门**是 source-first 算子与目标的独立身份，允许用 L5 编码作比较基准。
若只把目标 zeros 放进直和，或以 ac*ac≥0 取代缺失的谱隙/Weil identity，即停止。
经典普通有限紧图的 UV 首项已由 566 排除；无限/非局部/相对模型仍合法，但必须支付完整身份。
