## 2. 无零区域下一有效动作

从临界点的实际非 floor 行出发，明确需要怎样的 count 改进：
delta 在上述临界值附近、全部 slot amplitudes 的 mean x 接近 1/2。
先核实际 detector witnesses、相同角色的全部 Q_i 与 buffered zero location 是否产生
比原 R_* 更强的联合限制。任何新限制必须在同一 actual row、原系数类和原 masks 下证明。

候选可以是一个同时保留 witnesses 和全部 large prime-slot amplitudes 的联合 count，
或对原 marked/plain moment 的合法 capacity／κ 前件作真实强化。
不能直接取 κ<3/4、增加未准入的 prime supply、把 error slots 排除出 q，
或凭全导子一阶 prime 界获得新的跨槽独立性。

先在临界邻域付一个严格 count saving，再重算 continuous certificate；
同时检查邻域外仍有固定 slack。随后重验 floor、middle、outer、principal、
same normalizer 和 Δ→mesh→K→μ→target→internal height→external order。
单变量 geometry 网格、等号点的形式解释或重复调 b 都不构成下一推进。

## 3. 比例方向的实际最小对象

继续 238–241 的 physical-fiber-first 顺序。
在固定 high-product balanced cell 中，逐实际非零 determinant h、原 finite frequency shell
合并全部 I／II divisor blocks，再估计原 quotient 的 signed G-A。
共同 constant-density centering 是一个固定线性 projection，不能逐 channel 自适应选择。
必须保留 six-window、sharp factor/aperture cuts、所有 carrier、tail 和 cross terms。

规范 one-point 输入仅允许本身是 μ、Λ 或合法 fixed finite-ray 组合的因子。
消去一个 a-sum 后的 b-dependent error 不再是 b 的规范序列；
modulus uniform 也不是 averaged dispersion。固定 h 的 affine progression 只有 O(1) 整数，
不能用连续 PNT 主项代替两个 linear prime forms。

对实际 joint divisor fiber 可先利用共同 gcd 必须整除 h 的 support；
保留原方程的 residual affine congruence、完整 weights 与 Möbius signs。
[联合纤维报告](hybrid-joint-type-ii-fiber-research.md)已经证明 gq|h、精确 affine 重排及
whole physical core 的 coprime 投影，并在原完整 AF compression 上支付全部 proper powers。
[独立全文审查](joint-type-ii-full-review-radial.md)限定通过；
[整数审计](../../output/hybrid-joint-type-ii-fiber-audit.json)只验证有限恒等式。
无论采用 reciprocity、coprime joint inverse 还是 dispersion，
最终都须估计这些真实 residue weights，不能以 canonical generating function
或 divisor-coordinate 重写代替净预算。

若先去掉低 Lambda 或全部 proper powers，其合法作用只是在原全压缩中证明
Schatten–4 小量并保留完整 response 四范数前件；
不要反复优化这种 o(N) 误差来冒充比例主常数改善。

## 4. 下一验收口径

必须明确新估计控制的是哪一段原 response、哪些 cross terms 及其正规化。
目标为同一物理向量、共同 centering 和所有相关 cells 的 constant-size 一侧四阶预算，
不是各 channel 的大幂上界独立相加。
