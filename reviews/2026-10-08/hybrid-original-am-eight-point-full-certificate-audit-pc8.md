## 2. 需要证明的实际命题

令 `SC = 32768`，`SA = 100000000`，`cN = 805003`。令 `w` 为 AM13 profile 的归一化 Fourier 核的平方：

\[
K(x)=\int_{-1/2}^{1/2}v_{AM}(t)\cos(2\pi xt)\,dt,
\qquad w(x)=\left(K(x)/K(0)\right)^2.
\]

此处的核含 `sqrt 2` 模态和 12 个整数频率余弦模态；`K(0)=sqrt(2)*sin(sqrt(2)/2)>0`。证书核与研究使用的核必须保持这个归一化对应，不能换成只有整数频率的核。源中 `cert_wfun_eq`（18943）以 `rfl` 接上研究消费接口。

七个 gap 的未归一化目标是

\[
F(g)=\sum_{r=0}^{6}B_r g_r+
\sum_{(i,j,a,k)\in TS}a\,w\!\left(\sum_{r=i}^{j-1}g_r\right),
\]

其中

```text
BS = [28898, 57272, 75526, 80958, 75526, 57272, 28898].
```

`TS`（12810）列出 26 个非零配对项；零权重 `(0,2)` 和 `(5,7)` 不参与此和。需要全域证明

\[
g\in\mathbb R_{\ge0}^7\quad\Longrightarrow\quad F(g)\ge805003,
\qquad G(g)=F(g)/10^8\ge0.00805003.
\]

树实际证明稍弱的命题 `Pg`：`F(g) ≥ cN ∨ g6 < g0`。这不是漏掉半个定义域：`G` 的权重及核参数关于 gap 逆序对称，`PC8CL_G_rev`（18708–09）和 `PC8CL_cert_full`（18720–29）分别把两种端点顺序还原为完整命题。

## 3. 原子区间核：有向取整和导数

`DZ = 10^15`，恰有 `DZ = SC * 30517578125`，所以网格端点转换到核的整数尺度没有浮点误差。`SZ`（7204–22）表示有符号整数，`fl`/`ce` 分别向下/向上取整；负数不是简单丢弃余数。`IV`（7292–7312）的乘法使用四个角点，除法选择经证明为正的分母区间，所有取整方向与包络要求一致。

本次检查了 π 的有理包络、归一化常数 `GAM`/`RHOC`/`SIGC`/`TAUC` 的正性及 Taylor 余项传递。统一余项为 `13/5748019200`，用于 `|t|≤1` 上的三角近似；`sinc`、`sc1`、`sc2` 分别支付所需的 1、2、5 倍余项。`sc2` 近似中的十次项来自所选有限 `cos`/`sin` 组合，不能因它不同于直接的 Taylor 系数就把余项丢掉。

`CellA`（7547–7627）把整个小区间放在某个半整数中心的一侧，以约化角 `π|x-k/2|≤1` 控制三角部分。位于整数极点附近的 `sinc` 项单独取连续形式，其余远项使用有理函数及已核对的单调方向。`E0/E2L/E3L` 的正性检查控制相应除法。不能把只在中心点正确的有理式当成整个区间正确。

核、一次导数、二次导数的 π 因子与归一化因子对应实际的 `w`。`mabs`（9333）计算的是区间内绝对值的**下界**，不是上界：区间穿过 0 时它返回 0。于是 `KAn^2` 可给出整个闭区间的 `w` 下界。二次导数检查使用

\[
w''=2\big((k')^2+kk''\big),
\]

其中 `(k')^2` 也以绝对值下界处理，`k*k''` 则使用区间乘法下端点；下端点非负足以证明真实凸性。这不是以有限个二阶导数样本替代凸性。

`CellN`（9408–9422）以 `key = LN*KB + UN` 打包网格端点，`KB=2^20`。所有需要解包的检查都要求 `UN<KB`。`WZ/SW` 是完整实区间的 `w` 下界；`SW=10^13`。`okC=false` 时 `WZ=0` 仍合法，因为 `w≥0`。导数或凸性检查失败时不会生成一个未经证明的正界。

## 4. 下界表、导数表和切线的连续语义

`Pyr`（9495–9931）用 512 个块和上层二叉堆表示值下界。每个非零最细叶项通过 `CellN` 原子区间检查；每个父项不大于两个子项的最小值。块内取祖先区间、跨块取上层父区间都只会弱化下界。`lb` 的输出单位是 `10^-10`，原子检查乘 1000 才转到 `SW=10^13`，不能混用尺度。

`PyrD`（9937–10585）存储两方向导数下界。若 `P`、`M` 为两个字段，则其语义为

\[
\frac{P-2\cdot10^9}{10^9}\le w'(x)
\le\frac{2\cdot10^9-M}{10^9}.
\]

`PS` 对一个为 0 的字段明确不作导数断言。父节点使用两个字段各自的最小值，不能对整个 64 位打包整数直接取通常最小值。所有启用的切线均另外要求点表的两个导数字段至少为 1，故没有把缺省值 0 误用成 `|w'|≤2`。

两种 `dcov` 的燃料为 14。燃料耗尽返回 0，值下界降为 0，导数字段降为无断言；归纳证明仍覆盖剩余真实区间。因此，语义安全不依赖一个未写出的“14 步一定遍历完”假设。

`PTL` 点表使用低 32 位存 `w` 下界，接下来的两个字段存导数包络。每个字面列表须通过 `ptlOk`；未知点返回 0 是合法的空断言。选择器 `dsel`/`dpk` 只是路由合法数据，遗漏路由至多损失下界。

`REG` 的 16 段凸区间用首尾端点及连续的原子链表示；启用的链非空，相邻闭区间没有缝隙，终点必须相同。`rgB<rgA` 代表禁用段，不能启用一条在其中的切线。

切线外推有两条有效路径：凸区间内由真实 `w''≥0` 支持切线；区间外要么用全区间导数次序，要么使用 `tcheckZ` 的 1、2 或 8 片零阶检验。后一条在每片两个端点检查带导数包络的直线不超过整片的 `lb`；直线介于端点之间，所以片内也成立。`zpe` 的整数分割可产生零宽片，严格正宽片仍覆盖整个实际区间，零宽片没有造成覆盖缺口。

## 5. 每个 minorant/Farkas 叶子为何证明整个实 cell

`Cl`（11206–15）有四个列表：七个 gap 的 `L/U` 和 21 个长 span 的 `A/B`，全部以 `SC` 为单位。真实 cell 是这些闭区间约束的交集；没有把真实 gap 限定为网格上的点。

minorant 对每个 `TS` 项选常数下界与最多两条已证明有效的切线。四类模式的权重为：

| tag | 常数权重 | 切线 1 | 切线 2 |
|---|---:|---:|---:|
| 0（其余缺省） | 1024 | 0 | 0 |
| 1 | 0 | 1024 | 0 |
| 2 | 1024-m | m | 0 |
| 3 | 0 | 1024-m | m |

`m≤1024` 是逐项检查条件。把这些下界相加，令 `e_r = g_r - L_r/SC`，则 `0≤e_r≤(U_r-L_r)/SC`。导数包络给出的负系数只按最坏端点支付 `Ng_r`，没有未经验证的凸优化步骤。

Farkas 乘子由 gap/span 的上下界 slack 组成；`MulOKg` 证明对 cell 内每个真实 `g` 有

\[
0\le C_p-C_m+\sum_r(P_r-S_r)(SCg_r-L_r).
\]

所有乘子非负，越界索引被忽略而不是增加假约束。`fleaf` 的严格矛盾检查使整个 cell 为空；不能因一个测试点不可行就删除 cell。

最后的 `mcheckGZ`（12446–60）只有一个精确整数比较。设 `mv/mcp/mcn` 是各 minorant 的整数基值与修正项，则主比较为

```text
335544320000000000*cN
  + 10*(sum(a*mcn) + Cp + sum((U-L)*Ng))
<= 10240000000000*sum(BS*L)
  + 32768*sum(a*mv) + 10*(sum(a*mcp) + Cm).
```

这里同时支付了 `SC=32768`、导数分母 `10^9`、值分母 `10^10` 和组合权重 1024。`mcheckGZ_sound`（12461–12574）把该比较还原成对 **cell 内全部真实 g** 的 `F(g)≥cN`。已检查符号、负系数截断、Farkas 正负常数和尺度；未发现把样本结论当作叶子全域结论的步骤。

## 6. Closure、分裂和根覆盖

`matC` 初次把 span 下界与 `sum L` 取最大、上界与 `sum U` 取最小，保留原 cell 中所有真实点。`cupd`（12623–12797）利用连续 span 的三段望远镜恒等式更新 bounds。以 `x_i = sum_{r<i}g_r` 看，该更新给 `x_b-x_a` 加上已经合法的路径上下界。自然数截断减法利用 `x_b-x_a≥0` 保持安全；某些没有路径的更新被跳过，只损失紧度。

每个 gap/span 的分裂点为上下界平均值向下取整。两个子 cell 都包含分裂点；它们覆盖整个原闭区间，所有 `cupd` 后续收紧仍保留对应子 cell 的真实点。`St` 的 57 个字段为七组 `l/u`、21 组 `A/B` 和元数据 `M`；`M` 不进入真实 cell。

树格式（15533–71）需按以下规则复演，不能根据猜测的叶子标签解包：

1. 当前第一位为 1：分裂节点，再读 5 位轴号，共消费 6 位。轴 0–6 是 gap，7–27 按 `PR` 次序是 span；越界轴返回失败 0。
2. 当前第一位为 0 且 `u6<l0`：方向叶子，消费 **1 位**，证明 `g6<g0`。
3. 第一位为 0 且未触发方向叶子：第二位为 1 时执行 `fleaf`，为 0 时执行 `mleafP`；负载为 `w>>2`，成功返回 `pos+2+payload_consumed`，失败返回 0。
4. `walk` 在根上执行一次 `tm/matC`；递归使用 `walkC`，不能在每个节点重复执行 `tm` 来模拟源的消费位置。燃料 128 耗尽返回失败 0。

全非负空间首先逐坐标排除三类易证区域：`g_r≤1/2` 时 `w≥1/4` 与相邻 pair 权重足够；`g_r≥SMAX_r/SC` 时线性项单独足够；中间范围中标为 clear 的整段由原子 `WZ` 足够。`coverChk` 从 `SC/2` 开始检查相邻端点完全相接并走到 `SMAX`，每段均为闭区间；不能只检查各段下界而漏掉段与段之间的覆盖。

余下 bad 区间数量为 `[1,2,2,2,2,2,1]`，其笛卡尔积恰为 32 个根。根上 21 个 span 的初始 `A=0`、`B=W=1099511627776` 合法，因为总 span 至多 `7*KB≤W`。`root_cover`（11806–68）确实从以上逐坐标覆盖推出全部 `R_+^7`，随后逆序对称去掉方向分支。

## 9. 本次可以和不可以推进的结论

本次独立语义审查没有发现足以否定固定 PC8CL 下界算法的数学错误：原子区间、带导数误差的切线、Farkas、负系数支付、closure、中点分裂、非紧空间根覆盖与逆序对称形成一条完整的连续实数证明方案。值得吸收的内容是**先证真正的区间 minorant，再支付共享 gap 斜率和 span 约束**；这比只提高点采样精度更接近能准入的全域证书。
