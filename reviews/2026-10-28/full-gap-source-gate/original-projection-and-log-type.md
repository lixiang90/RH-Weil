## 3. 原范数、参数域与两个不同的P

原参数为每个先固定的 \(\lambda>0\)，不是prime上界X。偶函数上的Fourier为

\[
 (\mathcal C f)(x)=2\int_0^\infty\cos(2\pi xy)f(y)\,dy.
\]

PDF4明确规定偶函数空间范数为

\[
 \|f\|^2=\int_0^\infty |f(x)|^2dx.
\]

故原偶函数实现直接按半轴norm与项目positive-halfline实现对应，不另补一个2；亦非completed Mellin加权norm。dx中间向量与源du仍须经原酉log字典连接。

原文的 \(P_\lambda\) 是投到低区间的cutoff，Sonin正交投影另记 \(\pi_\lambda\)。候选的 \(P_b\) 对应后者，不能同原 \(P_\lambda\) 混名。为清楚起见改记

\[
 L_a=1_{\{|x|<a\}},\quad H_a=I-L_a,\quad
 \widetilde L_a=\mathcal C L_a\mathcal C,\quad
 K_a=\{f:L_af=0,\ L_a\mathcal C f=0\}.
\]

原Lemma2识别 \(K_a=\ker(L_a+\widetilde L_a)\)。必要低空间算子为

\[
 F_a=L_a\mathcal C L_a,\quad D_a=F_a^2,\quad
 R_a=(I-D_a)^{-1}.
\]

它们在低区间偶函数空间作用。原文给 \(F_a\) compact self-adjoint、\(\|F_a\|<1\)，故固定a的上述逆及 \(I\pm F_a\) 逆合法。没有a变化的统一条件数，更没有X成长后的restricted Gram费用。

## 4. Th4与Cor5的准确内容

Th4对任意complex偶 \(f\in L^2\) 给

\[
 \pi_af=f-R_a(L_af-F_a\mathcal C f)
             -\mathcal C R_a(L_a\mathcal C f-F_af). \tag{1}
\]

R_a的输出按低空间嵌入ambient空间。原页将D_a识别为低区间上限制于偶函数的sinc核；这是arch有限Fourier设施。

Cor5第一式以前件 \(L_af=0\) 给

\[
 \pi_af=H_af-H_a\mathcal C R_aL_a\mathcal C f.
\]

按相同低空间嵌入，旧完整bounded projector组织为

\[
 \pi_a=H_a-H_a\mathcal C L_aR_aL_a\mathcal C H_a. \tag{2}
\]

这是532／C005的双边界形式，第二项不能删。Cor5另两式分别要求 \(f=\mathcal C f\) 或 \(f=-\mathcal C f\)：

\[
 \pi_af=f-(I+\mathcal C)(I+F_a)^{-1}L_af,\qquad
 \pi_af=f-(I-\mathcal C)(I-F_a)^{-1}L_af. \tag{3}
\]

这些cosine特征条件不是一般Weil源r或finite-Euler像自动具有的条件。

原输入f是中间Hilbert向量，不是项目卷积源r。指定原页不含 \(B_X\)、\(P_bB_X^*B_XP_b\)、source trace、Γ／primepowers／pole身份或两参数relative费用；没有参数导数／rank2变化定理可领。不得将原参数化公式的存在当成这些结构已经运输。

## 5. log的正负方向

沿H₀及532的原酉字典

\[
 (Wg)(y)=e^{y/2}g(e^y),\quad
 \|Wg\|_{L^2(dy)}=\|g\|_{L^2(dx)},
\]
\[
 \mathcal Mg(t)=\widehat{Wg}(t)
 =\int_0^\infty g(x)x^{-1/2-it}dx,\quad
 \|\mathcal Mg\|_{L^2(dt/(2\pi))}=\|g\|.
\]

令 \(\mathfrak F=W\mathcal CW^{-1}\)、\(\tau=\log b>0\)，则低cutoff为 \(L_\tau=1_{\{y<\tau\}}\)、高cutoff为H_τ，且

\[
 M_b=WK_b=\operatorname{Ran}H_\tau
             \cap\mathfrak F\operatorname{Ran}H_\tau.
\]

对原 \(U_vh(y)=h(y-v)\)，cosine反向dilation给

\[
 \mathfrak F U_v=U_{-v}\mathfrak F,\qquad
 M_b=U_\tau H_+\cap U_{-\tau}\mathfrak F H_+,
 \quad H_+=L^2([0,\infty)).
\]

故两高腿在此表达里是+τ／−τ，不能把整个M_b写成 \(U_\tau M_1\)，也不能归一化第一腿后无声保持第二腿或完整Euler乘子。

按旧common-H₀共同gap，先fixed \(1<b\le b_*\)，不依X、r、Q或零点。ALL有限 \(pH_0\in M_b\)，所以旧较大W的finite-Euler像在 \(B_XM_b\) 内；不重证H₀或集中引理。

候选
\[
 \Pi_{X,b}=B_XP_b(P_bB_X^*B_XP_b|_{M_b})^{-1}P_bB_X^*
\]
仍使用原物理内积及全部inverse／returns。B_X非酉；Th4只识别中间P_b，不将此式变成 \(B_XP_bB_X^*\)，不提供cofinal压缩逆费。
