## 1. Typed source and target

The native theorem uses normal Noetherian affine X and identifies Wrat(O(X)) with the **reduced** finite relative-correspondence ring from X to A1_Z. Its product is the fiber product of two cycles followed by pushforward under multiplication of the A1 target, not ordinary composition of endomorphisms of X. The underline on Corr in (29) is visible in the page image: it quotients only the ideal Z Gamma0. In particular this is not a Picard/Chow quotient by all principal Cartier divisors.

The proposal deliberately takes the favorable base X=Spec C, which satisfies the stated native scheme hypotheses. This is not an integral descent from physical sources to objects over Spec Z. Over C each rational Witt element is a finite product

    F(T)=product_(alpha in finite C*) (1-alpha T)^(m_alpha),  m_alpha in Z.

Thus its nonzero ghost coordinates are finite integer-weighted power sums. Tensoring the cycle group with C would allow complex weights, but would still give only finite sums. Neither extension is supplied as an arithmetic source functor by the theorem.

For the physical r=e^(u/2)f in C_c^infty(R;C), use the actual ROOT prescription

    b_k(r)=integral_R r(u)e^(ku)du, k>=1,
    F_r(T)=exp(-sum_(k>=1) b_k(r)T^k/k).

The minus sign agrees with the source's Teichmuller convention [a]=1-aT: -T dlog F_r/dT=sum b_k T^k. Over C ghosts are injective (indeed coefficientwise invertible). Consequently

    F_(r+s)=F_r F_s               (Witt addition),
    F_(r*s)=F_r WittProduct F_s.

The second identity follows from absolutely convergent Fubini for each k. This is a nonunital convolution-ring map in ghost coordinates. It is not an ordinary C-linear map into the native integral cycle group, and it does not introduce a Hilbert metric or a positive Weil pairing.

For support in [-L,L], L>0,

    |b_k(r)| <= sqrt(2L)e^(kL)||r||_(L2 du).

These fixed-coordinate upper estimates are for physical r-du, not unweighted f-du. They do not have constants uniform in k or growing L. The logarithmic series converges for |T|<e^(-L), so compact sources even give a genuine analytic germ there. No original zero-extension Dlog estimate on an entire target object or full-Weil functional follows. In particular moment positivity alone is not positivity of Q_zeta.

## 2. The old591 compact source does not land in Wrat(C)

The actual old591 source is psi(u)=c exp(-1/(1-(16u)^2)) on |u|<1/16, zero elsewhere, with c chosen so integral psi=1; g=psi*psi# is nonnegative and positive on a nonempty open interval, with support in [-1/8,1/8]. This is the L1-normalized old591 source, not a replacement bump or the other old du-unit source. It is a legitimate compact physical source and has the already paid positive full-Weil value q0.

For every m>=0 and nonzero c in C^(m+1),

    c* H_m c
      = integral_R e^u g(u) |sum_(j=0)^m c_j e^(ju)|^2 du > 0,
    (H_m)_(i,j)=b_(i+j+1)(g),  0<=i,j<=m.

The strict inequality follows because a nonzero polynomial has finitely many roots while e^u ranges over an interval on which g is positive. Hence every H_m is strictly positive definite and has rank m+1.

If F_g were in Wrat(C), the finite factorization above would give

    b_k(g)=sum_alpha m_alpha alpha^k.

Every such Hankel matrix factors through the finite-dimensional coordinate set alpha and has rank at most the number of distinct alpha. This contradicts strict positivity for arbitrarily large m. The same contradiction works for arbitrary complex finite weights. Equivalently a rational logarithmic derivative gives a finite eventual recurrence; sufficiently shifted moment Hankel blocks remain strictly positive by the same integral proof and violate that recurrence.

Therefore F_g is a valid W(C) element but **not** Wrat(C). The proposal cannot assign this source an exact finite relative-correspondence class with these ghosts. This rejects the specified direct finite-cycle realization without making any assertion that all source maps into finite cycles must use these ghosts.

## 3. Native and physical principal roles are distinct tests

On A1_Z the cycle

which differs from the Witt additive zero 1; its first ghost is -1. This is not a defect in the native theorem, which concerns finite correspondence cycles rather than classes modulo rational equivalence. Native algebraic principality cannot be silently treated as disappearance in this ring.
