# 可恢复的长期重型研究流程

适用于数学、算法、科学调查和工程。保存能决定下一步的状态，
证据留在原件，摘要不当证明。

## 分层与唯一来源

| 层 | 内容 | 更新时机 |
|---|---|---|
| Goal | 原目标、强度、完整验收、用户约束 | 实质修订 |
| 宏观前沿 | 资产范围、因果缺口、未付前件、路线重准入与反事实选择 | 瓶颈/优先级改变 |
| STATE | 当前原因、瓶颈、唯一合同、下一动作、未知 | 每轮／中断前 |
| 战略 | 独立来源→实际比较→全域极限→后果的缺口图 | 瓶颈改变 |
| 合同 | 对象、量词、独立输入、负对照、预算、止损 | 任务开始／修改 |
| 证据 | 推导、来源版本、数据、代码、检查范围 | 取得时 |
| 决策 | 为什么选／停／转及重新准入条件 | 路线变化 |
| 节奏 | 已完成迭代及周期复盘 | 完整研究轮结算 |

STATE只引用原件，轮数只在cadence。哈希证明文件同一性，不证明数学。
Goal不积累进展；旧NEXT／PROGRESS不再是当前指令。

## 每轮开始与一页合同

检查文件、工作树和实际运行态，再回答：
用户最终要什么、哪些约束有效？当前合同为何值得做？
上一轮新增什么独立输入、哪个前件仍未付？
今天改变哪个缺口，有没有费用更小、信息更多的检验？
摘要与原件不符时记未知，源变动区分换行／版本／意义，不能无声消费旧审查。
文件active不能代替get_goal或实际进程。

合同写宏观贡献；对象、量词、域、符号、重数、极限顺序；
独立输入／一级来源和open前件；最便宜反例／负对照；
成功、失败、信息不足的交付；1–2轮预算、晋级与停止条件。
数值先冻结，改参数先留新版和原因，旧不利结果不删除。
对象存在不等于标签定义，有限对象不等于全域。

## 执行和结算

独立推导、反例与来源可并行，文件所有权分开，主代理核对前件后合并。
小修改不机械三审；重要结论需不同组织方式逆审。
适用检查通过后不机械扩大／重复。
证据区分proved、conditional、cited、experiment、obstruction、open；
每项附范围，执行完成不能把experiment改为proved。

结束用约五句话留下：问题、真实新增、未付前件、宏观影响、下一动作。
更新合同／STATE的证据、未知和进程，完整迭代才推进cadence一次。
完整失败准入也计一次研究轮；成果晋级须净后果；旧工具恢复、组织和补审计零轮。
转向写短决策，不让脚本凭退出码宣告数学进展。
运行 python scripts/research_state.py check 及 show；
checkpoint保存所引用核心文件哈希及快照，不认证证明或工具运行态。
按授权提交并核对远程SHA，只记可核实基线。

## 两个时间尺度及恢复

合同1–2轮止损，整体每4–8轮复盘，默认6。
复盘问瓶颈是否缩小、独立来源是否可用、替代路线价值、
最值得失败的检验、什么证据会推翻优先级。
转向不降低原目标，合同止损不重置周期；
重启旧路线须新来源、不同对象／拓扑或新有符号估计。

压缩／中断后按AGENTS读STATE→Goal→合同→最新决策→所需原件，
继承暂停路线、前件、停止条件和轮数，再核查未完成进程。
未知进程先核查，不重跑昂贵执行或冒称结果已保存。
用户补充默认指导原任务，明确取消／不兼容新目标才替换。

参考[OpenAI Docs长期任务memory与compaction示例](https://developers.openai.com/cookbook/examples/agents_sdk/building_reliable_agents_memory_compaction)。
这里采用工作区文件与检查点，不改平台压缩设置，不声称SDK memory或自动钩子已实现。

## 宏观选择与防止摘要漂移

恢复有两个层次：先恢复目标、真实缺口与行动理由，再恢复技术位置和待跑进程。
短入口应让另一个研究者说明“为什么上次停止、为什么现在选这一门、什么会使它失效”；
若只能读出下一条命令，因果恢复尚未完成。缺失项标unknown，读对应决策/原件再消费。

当前战略保存两个现实备选、各自新增输入和重新准入证据。按可能消除的关键前件、
失败能排除的合法范围、核算成本选择；没有主观完成百分比或第二套进展计数。
将严格新结果、决策信息、已有知识恢复分开陈述，三者都可改变动作，只有实际新结果
按原cadence结算。用户要求总结/完善目标不滚基线，不重置合同预算或周期。

每次总结把过时的当前结论直接替换，保留Git和决策中的历史；不累积相互冲突的尾注。
若摘要未改变未付前件和选择，写“瓶颈未变”，不要把组织改善写成核心进展。
重要纠错沿依赖链传播：先核原件，再改原消费收据、前沿、STATE、合同/战略和当前总结。
保存哈希和结构检查完成后仍需语义逆审，不能由文件一致性推出研究结论一致性。

科学研究对应核总体/外推与混杂，算法研究核模型/规模/复杂度，工程核真实路径/部署与回归。
通用流程保存这些责任及选择方法；专门证据仍在项目中，不创建另一份全历史数据库。

## 宏观恢复的最低内容（2026-10-14增强）

每个新Goal冻结已有成果基线，旧完成/审计/最强资产作为前件，不重复验收新目标。
稳定Goal不保留易过时的“当前第一合同”；当前动作只从STATE恢复。
宏观前沿保持一个短文件：已付因果箭头、每条成果的对象/域/量词/依赖与消费范围，
最小未付前件、路线失败范围和重新准入条件。长历史/证书目录只链接原件。
STATE目标保持6–10KB以内，16KB为硬上限；移出详细历史不删除原证明或不利结果。

每次候选选择先写反事实：候选成立但统一费用仍欠时，宏观后果是什么；
若最便宜检验失败，哪个现实备选会更有价值；什么实际新证据会改变这一选择。
不能只写“继续探索”或把未付条件改名。实质纠错明确更新依赖它的消费范围。

净后果先接受最强基线反事实：除了正在使用的表示，还检查旧资产的其他分解和
可立即蕴含的强后果。只优于一个弱旧子界不算整体改进；新发现旧强消费链留在
基线范围，不再登记新forcing。比较对象、规范、全部费用和适用参数必须相同。

另对照最新结算前沿去重：固定基线用于整个Goal验收，不能让晚于基线的旧结算在下一轮重新计功。
恢复的相同命题、直接推论和已付费用仍为输入。明确这轮跨越的是来源合法、同源费用/core覆盖，
还是成长净后果/对象识别；不同阶段不继承proved标签。连续只付来源接口时提前策略复核，
冻结一个具体可判真伪门，再做依赖它的研究；复核与入口恢复仍零轮。

每轮结算保留六项：问题/新增独立输入/未付前件/瓶颈变化/停止与重准入/唯一下一动作。
科学调查另核样本总体/混杂与误差，工程另核用户效果/部署边界/回归，
算法另核复杂度模型/分布/基准；可迁移的是同对象证据责任，不是某领域的专门术语。
合同列预算和已结算note引用，原cadence仍唯一计数；不按工具/代理/文件推算轮数。

## 恢复盲测与真实未知

新轮/压缩/中断后按AGENTS→README→STATE→check/show→Goal→宏观前沿→合同/决策恢复，
再核必要原件及Git/工具Goal/进程。宏观前沿与最近结算引用纳入checkpoint。
一页恢复答出：完整完成门和基线；最新资产准确范围；最关键未付箭头；
下一动作与备选的选择理由；失败/新证据如何改策；哪些运行事实必须重新现场核。
答不出记unknown、定位原件，再推进不依赖它的工作，不用摘要自洽蒙混。

pending必须记handle种类/值、状态、输出路径、最后观察和安全恢复动作。
无pending只表示那次实际盘点结果，文件active/empty数组不替代现场查询。
优先读取实际已有日志/result，确认能否继续原会话，再决定重跑；不无声重复昂贵动作。

结构check只检当前Goal版本/基线绑定、引用、迭代去重和进程记录格式，
不判数学、自动完成、自动止损、自动计轮或给予新权限。
重大路线改变可由独立代理只读短入口做盲测；通过也不升级证据等级。
当前Goal的completion audit须匹配当前Goal路径、冻结基线和规范LF版本指纹；
旧通过审计只留历史。新Goal组织启动、总结和这套规程本身均零数学轮。

## 来源筛选与纠错传播

新增“前件闭合记录”只放在原证明或root消费收据，不再造一份全历史数据库。
字段为对象/norm/域、源与成长量词/极限顺序、每项依赖及版本/paid或open、已付误差、
覆盖/补空间/耦合、实际消费方向、最强旧及最新前沿扣除后的净后果。
科学调查对应记录总体/混杂/测量与外推；算法对应模型/分布/规模与复杂度；
工程对应真实用户路径/权限/部署范围及回归。仅结论标签相同不能跨这些范围消费。
恢复先读该记录，再读需要的原证明；摘要不是合并多个conditional稿的授权。
哈希变动先区分字节、依赖或量词改变，后两者须重核下游消费。

连续两个合同只恢复来源/旧等价或只付非核心特殊类时，从已有决策触发策略复核，
不新增counter。下一数学合同先写三句：独立输入；可付款/可反例的实际门；
成功后扣最强已有后果仍能改变哪条箭头。若第三句尚无具体内容，
只执行一个有原件章节定位和停止条件的来源审查，不预先登记新数学合同或净进展。
有价值的新source费用可以结算，但不能用它绕过完整效果/覆盖门。
复核、组织、原件恢复均零轮；不利用零轮规则串行换标签，也不因此暂停长期Goal。

新来源先写三行：原件独立给了什么；最强旧资产已能推出什么；
新来源能检验哪条未付箭头。若第三行只有目标改名或旧恒等式，入口停止零轮。
连续来源恢复/入口停止时先策略复核，不利用零轮规则无限串行换候选。
有研究价值的下一合同必须冻结一个能付清或被反例否定的具体门，及失败后的现实备选。

反例只消费它实际否定的对象与量词。某计算流程没有合法输入，
不代表同一量的直接定义不存在；粗上界不能充当必要成本，特殊样本或子类不能当总体。
发现具体逃逸后回撤依赖该错误的结论，在前沿/STATE/决策/证据中一致标明已付与未付。
新子类结果附覆盖率/补空间/耦合门，不将其升级为整体效果。
工程和科学任务对应检查替代实现、选择偏差、控制组与总体外推，仍以实际证据为准。
