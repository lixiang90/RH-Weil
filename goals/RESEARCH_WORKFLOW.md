# 可恢复的长期重型研究流程

适用于数学、算法、科学调查和工程。目标是让压缩后的研究者仍能做出有证据的选择。
保存目标、因果责任和决策；详细证明／数据留在原件。本流程不认证研究结果。

## 1. 稳定目标、短前沿和唯一执行状态

| 文件层 | 回答什么 | 更新时机 |
|---|---|---|
| Goal | 最终要改变什么、强度、基线、完整验收、约束 | 用户实质修订或验收规范改变 |
| 宏观前沿／当前总结 | 已改变什么、准确范围、最小缺口、合法逃逸、路线价值 | 新结果或瓶颈／选择改变 |
| STATE | 为什么做这一门、当前阶段、唯一下一动作、unknown／真实handle | 动作阶段转换、每轮及中断前 |
| 合同 | 对象、量词、输入、可判门、负对照、预算、停止／重准入 | 准入及实质变化 |
| 原件／消费收据 | 原证明、数据、版本、误差、前件闭合、消费方向 | 出稿、审查、消费时 |
| 决策 | 为什么选／停／转，什么证据会改变选择 | 路线改变 |
| 原cadence | 完整研究轮与宏观复盘 | 统一结算一次 |

Goal不积累易过时的当前合同；STATE只引用必要原件，目标6–10KB，16KB为硬上限。
当前总结替换过时判断；历史由决策／原件／Git保留，不持续叠加冲突尾注。
旧NEXT／PROGRESS／镜像不是当前执行源，不另造任务数据库或第二套轮数。
新Goal冻结已有成果；旧完成是输入，不能再次验收。普通完善不滚基线或重建运行实例。

## 2. 恢复须验收行动理由

新轮、压缩或中断后按本仓AGENTS：读AGENTS、README、STATE，执行check后show，
再读Goal、前沿、唯一合同、最新决策和必要原证据。核实际工作树、工具Goal和运行进程。
这六个答案必须能从短入口和原件恢复：

1. 用户最终验收什么，冻结基线和仍有效的约束是什么。
2. 最强可消费资产及依赖链是什么；不能只读最新打印的弱界或结果标签。
3. 最小未付箭头是什么；何种独立输入能让它闭合。
4. 上次为何停，当前动作成功／失败分别改变什么，为什么优于两个现实备选。
5. 什么具体证据会推翻选择；哪些付费、变尺度、源适应或其他合法修复仍未排。
6. 文件已出、审查已完、root已消费和实际Goal／handle／进程分别处于什么状态。

答不出就标unknown并定位原件，不以摘要自洽补前件。恢复质量可让独立研究者只读短入口盲测；
能解释相同选择与失败范围才通过。盲测检可恢复性，不检证明真伪。
一条新命令不等于完整恢复；读更多历史也不自动增加因果理解。

## 3. 先选责任，再开合同

将目标画成一条可检验链：独立输入→同对象／测量→完整误差与覆盖→尺度外推→最终后果。
合同须说清承担哪一段；多个局部proved不能自动闭合更强箭头。
比较两层旧资产：冻结基线用于整个Goal增量，最新结算前沿用于本轮去重。
跨表示检查最强已有后果和可立即蕴含的exact分解，不能用弱旧子界报整体净改善。

新研究合同冻结三句：原件独立给什么；能付款或反例否定的实际门和最便宜负对照；
成功扣最强旧后具体改变哪条未付箭头。再写对象／norm／domain-range／元素角色、
源和尺度量词、极限顺序、所有依赖／误差、1–2完整轮预算、成功／失败／信息不足交付。
固定数值输入；改参数留版本和原因，旧不利证据不删除。
战略保两个现实备选，比较能消除的关键前件、失败信息和核算成本，不用主观完成百分比。

探索来源与兑现核心分开。来源门可先做一次具体原件章节审查；没有净后果则不预建数学合同。
连续source-only／非核心合同从既有决策触发提前复核，不新增counter。
下一门必须有可检查的信息差：新独立输入，或足以改变路线选择的具体test。
同一coverage／coupling缺口仅换章节、表示、paper名不通过；unknown domination不算input。
门后立即停／晋级，不将零轮来源链当成持续核心进展。没有证据不证明路线数学上不可能。

## 4. 原件消费与语义依赖

前件闭合记录只放原证明或root收据：对象／norm／domain-range／角色；源与成长量词／极限；
依赖版本及paid/open；全部误差；实际系数方向；覆盖／补空间／coupling；最强旧净后果。
先核输入真在映射范围、关系被正确消去、非退化对象仍可见，再谈符号和运输。
来源合法、单标签、fullflat标签、实际系数合成、全域效果不能在压缩中合并。

证据分类proved、conditional、cited、experiment、obstruction、open，并附准确范围。
出稿→独立逆审→root消费→统一结算逐阶段保存，不由文件存在或退出码升级等级。
前件open则对应下游conditional；依赖对象／范围／角色／norm／量词意义变化先freeze，
追加纠正与重审后解冻，保原件和未受影响资产。byte hash只认版本，结构check不认语义。

失败只消费实际否定的量词。没有合法算法输入不排直接定义；粗上界不是必要费用；
子类／代理指标不代总体。重要方法边界需核合法付费修复与变尺度／适应／joint逃逸。
发现逃逸后缩回失败类，修正原消费收据、前沿、STATE和决策，不把整个方向一起宣布失败。

## 5. 执行交接与真实进程

并行原推导、来源和反例用独占输出；root先对齐对象和前件后消费。重要结论用不同组织逆审；
小可逆编辑不机械多审。完成适用验证后不因形式重复扩大测试。
阶段转换即时同步STATE的stage/action/pending，不等到回复末尾。
复用handle核当前任务、输出和最新观察；旧task完成不表示新task完成。

pending记录handle类型／值、状态、输出路径、最后观察和安全恢复动作。
空pending只是那次盘点；文件active和空数组都不代现场查询。
中断先读实际result／日志，确认原会话是否可继续，再决定重跑，避免重复昂贵执行。
用户补充默认指导当前长目标，明确取消／不兼容才替换；已授权工作不重复问许可。
开始运行分别核同Goal实例active与当前准入动作确已执行，不能靠重建Goal或重置cadence证明。

## 6. 结算和两个时间尺度

每次完整研究迭代统一保存六项：问题、新增独立输入、未付前件、瓶颈变化、
停止／重准入、唯一下一动作。来源合法／纠错决策、费用、whole净后果、关键瓶颈、最终完成分开。
整体费用严格改善可是真结果，仍要说明规模和未付覆盖；标签不能替最终验收。

新严格费用／新完整准入反例按研究轮结算；来源恢复／旧推论／组织／审查／推送0轮。
失败的完整研究准入也计一次；不以source0标签藏新数学工作，也不按文件／工具／代理计轮。
轮数只消费原cadence一次。合同1–2轮止损，整体每4–8轮复盘，默认6。
重大反例或连续来源停滞可提前策略复核，复核不重置周期，不降低原目标。
复盘核最强旧、瓶颈缩小、独立输入、失败信息、替代路线和推翻选择的证据。

check/show只验证引用、版本、基线、计轮和进程格式，不认证数学／实际运行或授权。
checkpoint记核心原件的规范LF版本及快照，不证明结论。按授权保存，现场核远程完整SHA与clean。
宏观验收绑定Goal版本和固定基线；旧审计保历史。回复、组织启动、合同完成和推送不是长期完成。
工具paused／blocked／complete遵守实际权限和终态规则，困难或未知本身不构成完成。

## 7. 跨领域的证据责任

| 领域 | 必须恢复的对象与验证责任 |
|---|---|
| 数学 | 原对象／域／norm、符号、全量词、误差、覆盖／耦合与非循环后果 |
| 科学调查 | 样本总体、测量、混杂、对照、误差和外推；机制假说不代因果证据 |
| 算法 | 模型、分布、规模、复杂度与完整基准；局部benchmark不代普遍效果 |
| 工程 | 真实用户路径、权限、部署边界、正确性与回归；模块通过不代端到端交付 |

可迁移的是责任链、反事实选择和可恢复交接，专门证明不能转写成其他领域的事实。
实际用户验收优先于代理指标。方法经验放本流程，项目最新成果／失败回原件与决策。
