# 当前研究目标的周期复盘

按用户2026-10-08的要求，每4–8轮研究复盘一次，默认每6轮。
重要的证明路线转折、实质反例或前件变化可以触发提前复盘。

“一轮”指一次完整的继续研究迭代，可能包含多个子代理、笔记和检查。
工具调用、子代理数量和新文件数量不单独增加轮数。
从本次复盘交付后开始计数；状态保存在[节奏记录](review-cadence.json)。
普通状态汇报和同一轮内的用户补充不算独立研究迭代。

每次复盘必须检查当前工作树和证据，然后回答：

1. 哪些成果已经证明并独立复核，哪些仍是条件结论、候选或有限诊断？
2. 哪些变化改善了原主项、实际中心矩、零点比例或无零边界，哪些只改善辅助误差？
3. 真正瓶颈是否改变？最近的投入是否仍朝完整目标推进？
4. 下一周期最值得证明的具体算术命题是什么，其所需节省有多大？
5. 哪条路线应继续、减少投入或暂时停止？什么证据会改变这个决定？

复盘写在 `goals/reviews/`，从研究看板链接；公开README保持项目介绍。
复盘中明确保留原完整目标，不以已完成的辅助结果重新定义成功。
有限检查、模型常数、未核实的引用前件与实际无限定理分开记录。
提交时记录该轮有证据的状态变化；复盘完成后重置轮数。
下一轮继续研究时先读节奏记录，完成该轮后推进计数；达到4轮可提前复盘，达到8轮必须复盘。
