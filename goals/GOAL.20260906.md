## 二、事实基线与证据边界

### 1. 已采用的外部与内部基线

Alpöge–Furman 的预印本核对至 arXiv:2608.13637v2（2026-08-19），Lamzouri 的新短证为 arXiv:2609.02882v1（2026-09-02）。MT 常数为
\[
 C_0=\frac32-\frac1{\sqrt2}\cot(1/\sqrt2)
 =0.6725007036794116\ldots.
\]
这是历史证明基线，不是全部公开研究的最新数值。

笔记 304 的内部复核结果为
\[
 p_*=\frac{C_0-1/40000}{1-1/20000}
 =0.672509329145868939\ldots.
\]
其不同零点比例结论为 \(0.836254664572934469\ldots\)，依赖本文的完整重数/惯性账本，不能只从简单零点比例套用一般不成立的 \(D\ge(N+S)/2\)。

304 的主链和纯有理三点证书已在所列范围内复核，但核心凸谱余项、三点根加法机制与比例公式已有 ainta 的直接公开对应；其三点数值 67.2519767114% 更强。因此 304 保留为小型复核基准，不宣称首次三点机制、世界纪录或外部同行评审完成。

### 3. 四矩路线仍有实际算术缺口

同一假想全四矩数据 \((1,1,4/3,2,13/4)\) 在补足误差和矩极限条件后给出 \(16/21\)、\(37/42\) 的条件后果；13/18 保留为历史比较。

实际 MT 四阶路线的约 0.756902666、0.878451333 仍为条件结论：实际合并后的有符号四阶算术预算未证，不只是数值证书等待复查。

若目标比例为 \(p\)，采用笔记 228 的完整假设与
\[
 B_4<\frac{(1-v)^2}{p}-1+2v.
\]
以待审 \(p=0.673399\) 作比较时，平窗 \(v=1/3\) 的阈值为
\(0.326668306770742\ldots\)，实际 MT 窗 \(v=1-C_0\) 的阈值为
\(0.326602198303353\ldots\)。原 \(0.3275499074\ldots\) 只对应平窗超过旧 \(C_0\)。设置比较值不等于认证了该后续主张。

## 四、本周期的精确问题与可证伪目标

保持302／304的同一实际有限前缀0<gamma<=T、全部正负列、重数、sharp MT半宽A=log(T)/2和原始高度规范。
记原算子为mathsf A=P-N，P是全部正秩一项之和，不是正谱部分。选出的负测试列矩阵用Q，避免与原始N因子混淆。

取满足316固定参数及几何前提的有限互不相交深点簇Cj，中心间距至少D=T^theta，直径rT=o(1/log T)。
每簇有一个深度至少d0的实际目标；簇外全部深度>s的点距各簇至少D。
Q的第j列为uj=hj/||hj||，Wj为簇内原始负列总质量，M可以随T增长。
本阶段不预设实际存在这些簇，不把Wj当原算子负谱迹。

预定4–6轮，必要时最多8轮，至少完成以下不同数学动作：

1. **原始共同Gram**：证明或反驳||Q*Q-I||<=C log(T)/D的统一估计，常数不得依赖M；
   将其用于一个合法正收缩效应，明确负迹求和的分母及全部正项。经典部分按重建分类。
2. **增长列数的成本审计**：针对V=R^{-1}Q，R=lambda(P+lambda I)^{-1}，
   检验逐列小误差能否升级到||V*V||；给具体反例或真正统一界，不默认独立或正交。
3. **实际几何接口与共同日程**：用同一P、一个lambda和一个效应处理所有簇，
   核算近簇、其他选中簇、未选中深点、浅点和临界线的成本。
   如新增簇数／质量／深度条件，明确付出的代价；检验lambda/||P||是否确有节省。
4. **净收益与下一缺口**：至少对一个非平凡增长簇数的参数范围核算真实收益，
   或证明此前未排除的具体共同日程障碍；将几何前提、点数上界和可验证输入分开。
   完成必要原始文献比较、可复跑的有限证据及独立证明逆审。

不得把Hilbert–Schmidt界中sqrt(M)遗漏；不能把逐列Rayleigh下界未经共同效应就相加。
若只能把lambda升到整个||P||而无集体净预算改进，记录原因并测试严格不同的新机制；
若只是已有定理的完全对应或纯参数改名，按第五节切换，不靠文档数量验收。

## 五、探索准入、晋级与切换

探索准入只要求一页任务单：准确命题、参数／量词、不同于旧失败的一个新机制或新信息、已有界与所需界的比、与实际对象的接口、已知反例、成功／停止条件。**不要求关键新估计在探索开始前已经证明。**

成果晋级仍要求独立的新数学输入或有实质内容的严格障碍；不能以笔记数、计算时长、变量减少、等价表示或 RH 下校准替代。

当前优先VIS-CL-GRAM，完整证明与原始文献复核为辅助。最多同时一条数学主探索和一条模型／复核辅助。根据首周期结论依次评估以下候选，允许有证据地调整次序：

## 六、持续研究的工作流与阶段管理

通常每周期 4–6 轮，必要时最多 8 轮；轮次按实际数学动作记录，不由工具调用次数凑数。

1. 从唯一当前队列选有限问题并写任务单；前向推导与反例搜索并行。
2. 保存推导、失败原因、确切计算与版本；定量界必须把关键隐常数／参数依赖和净收益写明。
3. 对候选逆审定义、引用、极限、Gamma／尾项、符号、惯性和重数账本；出现实质异议先纠错。
4. 按用户已授予的持续授权，直接使用只读子代理做独立复核，不再重复征求本 GOAL 的复核授权。写入核读范围和异议处理，不冒称外部评审。
5. 每周期结算“新增输入、已排除范围、仍缺什么”，更新唯一队列、目标进度和保存状态；成功后开展紧邻的下一有限命题，失败后按第五节切换。
6. 有意义的新结果及时按第八、九节保存文献、commit／push。研究状态与版本保存分开；无变化不空提交。

不得仅凭修订GOAL、启动工具、重述316或再次判定旧路线缺输入就结束整个阶段。
若出现实际权限／资料阻塞，继续独立任务，并按 GOAL 工具的真实阻塞规则处理；数学尚未解出本身不等于需要用户确认。

- 准备结束工作或交接时，将未完成证明、开放问题、复现命令和下一步落盘，再提交并推送。重大成果或重要修正提交后及时推送，不必等待整个周期。
- 没有实际内容变化时不做空提交。

每次保存须做到：

1. 提交相关笔记、看板、论文源文件、必要计算与证书、文献及索引，明确它们的数学状态；未证草稿可以按 [C/E/O] 保存。
2. 本版目标文件位于 Git 根目录外。保存目标变更时，须将本版及必要历史归档同步到仓库内的版本化路径，例如 goals/，再纳入提交；不要误以为仓库外的文件已被 Git 保存。
3. 检查本次差异并运行与变更相关的验证。排除临时渲染、缓存和下载残片；稳定论文版本需要时再重编 PDF，不为每次记录更新重跑全部数学计算。
4. commit 信息说明保存了什么以及重要状态变化。推送后确认远程对应提交，记录分支、commit SHA 与同步结果。
5. 推送失败时保留已完成的本地 commit，记下错误与未同步状态并在网络恢复后重试；不要把本地提交成功记成推送成功。遇到远程更新先正常处理差异，不用强制推送覆盖他人或既有历史。

网络连接或推送遇到问题时，可按原 GOAL 第九节的提示尝试本机代理 http://127.0.0.1:10808。在当前 PowerShell 会话中设置：

```powershell
$env:http_proxy = "http://127.0.0.1:10808"
$env:https_proxy = "http://127.0.0.1:10808"
```

若使用 CMD，原提示对应的命令为：

```cmd
set http_proxy=http://127.0.0.1:10808
set https_proxy=http://127.0.0.1:10808
```

设置仅对当前终端会话及其启动的进程生效；设置后重试文献下载或 Git 推送，并核实操作结果。

版本保存与数学验收分开。commit、push、CI 或 PDF 编译成功仅说明相应保存/检查完成，不证明 RH、原创性或论文级定理成立。

## 十、本阶段验收与持续推进边界

本阶段区别于已完成的phase 1和phase 2。全部满足后才可标记本阶段GOAL完成：

1. 第三版目标、phase 2原始历史、镜像、当前队列和执行账本已保存同步，旧版准确状态不被覆盖。
2. 按第四节完成至少4轮不同的数学动作，处理原始Gram、增长列数、同一P/R及实际几何接口；
   单一经典引理或一次失败不满足多轮研究要求。
3. 至少有一项超出316已确认基线的、可独立表述的实质成果：在非平凡增长簇数下的统一集体预算／严格条件削减，
   或排除此前未排除的具体方案且明确逃逸条件的有用严格障碍。纯逐列推理或旧障碍换名不算。
   若文献已有完全对应，准确归类并继续寻找实质推进，不宣称世界优先权。
4. 新结果完整证明、固定／增长参数、外部输入、必要证书、原始文献比较和内部独立复核异议闭环。
   文件校验、有限实验和外部定理引用分别限定其真实核查范围。
5. 净收益、条件性范围及下一有限任务已写清楚；实际簇存在、全局正性、Gamma、比例与RH的开放状态一致。
6. 成果已commit并push至指定GitHub仓库，核验远程SHA；无变化不空提交，同步失败显式未完成。

阶段完成只表示本有限研究周期达成，不能称作RH、最新世界纪录或全部旧笔记已认证。
一个尝试失败不缩小以上要求；继续研究或依第五节切换。
